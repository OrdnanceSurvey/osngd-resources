# Data Schema Versioning

This directory contains a single maintained reworking of the feature type **data schema version tables** (as referenced under the individual [Data Structure Information](https://docs.os.uk/osngd/data-structure/data-structure-information) documentation pages).

The information is provided in CSV and JSON formats. You can also dynamically view the details at https://labs.os.uk/prototyping/osngd/data-schema-versioning/.
